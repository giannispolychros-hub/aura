# AURA — Architecture Reference

## Protocol Layers
1. Question Classification (FACT / ANALYSIS / PERSONAL)
2. First-WHY mechanism
3. Lens inference (SIMPLIFY / CHALLENGE / PERSPECTIVE / EXPLORE)
4. Clarification threshold
5. Root Cause Insight + Verification
6. Resolution Engine (resolved / partial / unresolved)
7. Termination Protocol

## Memory Schema v1
- trajectories: thinking quality per category over sessions
- obstacles: recurring patterns (stable at 3+ confirmations)
- anchors: open decisions
- qualityLog: session signals (no content)

## Visual System
- AURA ERGO SUM: 11-letter progressive illumination
- Clarity surge: brief background pulse on insight
- "To the point of mind": closing distillation
