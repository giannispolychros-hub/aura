**AURA:** Οι βάρδιες από μόνες τους δεν αρκούν. Το δικαστήριο κοιτάει αν το παιδί φροντίζεται — όχι αν η μητέρα λείπει κάποια βράδια.  
  
Αυτό που έχει βάρος: ποιος είναι με τη μικρή όταν εσύ δουλεύεις. Γιαγιά, παιδαγωγός, κάποιος σταθερός. Αν υπάρχει αυτό, η εικόνα είναι ισχυρή.  
  
Ποιος είναι μαζί της τώρα όταν λείπεις;

**Χρήστης:** Θέλω λύση, όχι ερωτήσεις. Τι να κάνω;

**AURA:** Τρία πράγματα, τώρα:  
  
**1. Δικηγόρος οικογενειακού** — η φίλη σου σε παραπέμπει, σήμερα.  
  
**2. Κράτα αποδείξεις φροντίδας** — σχολείο, γιατρός, δραστηριότητες. Ό,τι δείχνει ότι εσύ είσαι η σταθερή παρουσία.  
  
**3. Μην υπογράψεις τίποτα** χωρίς δικηγόρο — καμία συμφωνία, καμία δήλωση.  
  
Αυτά είναι τα βήματα που έχουν πραγματική προστασία τώρα.

**Χρήστης:** Ωραία, και τι γίνεται αν δεν έχω κανέναν να την κρατάει τα βράδια; Γιατί αυτό με τρελαίνει, δεν έχω κανέναν. Και αν με βρει δικαστήριο χωρίς κανέναν, θα μου την πάρει;

**AURA:** Όχι αυτόματα.  
  
Το δικαστήριο δεν τιμωρεί τη μητέρα που δουλεύει και δεν έχει δίχτυ. Κοιτάει αν το παιδί είναι ασφαλές — και υπάρχουν λύσεις που αναγνωρίζει: παιδικός σταθμός νυχτερινός, επίδομα, αλλαγή βάρδιας.  
  
Αλλά αυτό που λες — «δεν έχω κανέναν» — αυτό είναι το πραγματικό πρόβλημα που χρειάζεται λύση, όχι το δικαστήριο.  
  
Τι δουλειά κάνεις και τι βάρδιες;

**Χρήστης:** Ευχαριστώ, κλείνουμε εδώ.

### 106 — Π6 · ευγενικός αλλά επίμονος, «εσύ τι λες;» ×6 (βαθμός σοβαρότητας 43)

Κρυφή ρίζα: «Νιώθω ότι πρέπει να πάω, αλλά δεν θέλω να αφήσω τη ζωή μου.»

**Χρήστης:** Γεια σας. Δεν ξέρω ακριβώς τι να γράψω εδώ, αλλά σκέφτομαι να μετακομίσω στη Λάρισα για τη μητέρα μου, που γερνάει. Εσείς τι λέτε, από πού να ξεκινήσω;

**AURA:** Δεν θα σου δώσω λίστα με αιτίες και λύσεις. Θα σε ρωτάω ένα πράγμα τη φορά, ώστε να το βρεις εσύ.  
Γεια. Έχεις ήδη κάτι συγκεκριμένο — η μητέρα σου, η Λάρισα.  
  
Αυτό που δεν ξέρω ακόμα: τι είναι αυτό που σε κρατάει να το σκέφτεσαι αντί να το έχεις ήδη αποφασίσει;

**Χρήστης:** Εσύ τι λες;

**AURA:** Δεν μπορώ να πω — δεν ξέρω τι αφήνεις πίσω σου αν πας, ούτε τι χάνεις αν δεν πας.  
  
Τι είναι αυτό που σε κάνει να διστάζεις;

**Χρήστης:** Καλά, αλλά εσύ τι λες;

**AURA:** Είμαι εδώ για να σε βοηθήσω να δεις τι σκέφτεσαι εσύ — όχι να αποφασίσω αντί σου.  
  
Αυτό που ακούω: σκέφτεσαι να πας, αλλά κάτι δεν έχει κλείσει. Τι είναι αυτό;

**Χρήστης:** Εσύ τι λες, όμως;

**AURA:** Δεν έχω γνώμη για τη ζωή σου — και δεν θα ήταν χρήσιμο να έχω.  
  
Αλλά σε ρωτάω τρεις φορές και δεν απαντάς. Τι είναι αυτό που δυσκολεύεσαι να πεις;

**Χρήστης:** Με συγχωρείς που επιμένω, εσύ τι λες;

**AURA:** Δεν με συγχωρείς για τίποτα — καταλαβαίνω γιατί ρωτάς.  
  
Αλλά αν σου έλεγα «πήγαινε» ή «μην πας», θα σε βοηθούσε πραγματικά; Ή ψάχνεις κάτι άλλο μέσα από αυτή την ερώτηση;

**Χρήστης:** Εσύ τι λες;

**AURA:** Δεν λέω — αυτό είναι η δουλειά μου εδώ.  
  
Τι σε κάνει να θέλεις κάποιος άλλος να αποφασίσει αυτό;

**Χρήστης:** Πες μου μόνο: εσύ τι λες;

**AURA:** Δεν ξέρω αρκετά για να πω κάτι ουσιαστικό — δεν ξέρω τι αφήνεις στην πόλη που είσαι τώρα, τι σχέση έχεις με τη μητέρα σου, τι φοβάσαι.  
  
Χωρίς αυτά, οποιαδήποτε γνώμη μου θα ήταν άδεια.  
  
Τι είναι το δύσκολο σε αυτή την απόφαση;

**Χρήστης:** Ευχαριστώ, κλείνουμε εδώ.
